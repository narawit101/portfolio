This personal portfolio serves as the definitive engineering showcase for **Narawit Soiaudom**. Success is defined by visitors immediately grasping core technical strengths within 30 seconds, exploring verifiable GitHub repositories and live demos, and reaching out via Email or LinkedIn for job opportunities.

## Positioning

Unlike generic visual-only templates or static portfolio mockups, this platform is positioned around **Full-Stack Product Completion & Real-Time Engineering**. Every featured project is a complete, functioning ecosystem—from performant frontends and clean component architectures to real-time WebSocket relays (Socket.IO), low-latency caching (Redis), relational database modeling (Prisma/PostgreSQL), and cloud serverless deployments.

- **Screening & Review**: Evaluated during fast-paced candidate review cycles on desktop multi-monitor setups, laptops, and mobile devices directly from LinkedIn or CV links.

## Capabilities and Constraints

- **Framework & Performance**: Next.js 16 App Router (Turbopack), React 19, and Tailwind CSS v4 delivering instant hydration and static sub-second page performance.
- **Strict Bilingual Localization**: 100% of visible UI text, project overviews, technical highlights, and instructions are localized into structured `LocalizedText` dictionaries (TH / EN).
- **Interactive Project Showcase**: Deep modular modal dialogs with copyable test credentials, step-by-step role walkthroughs, and a Fullscreen Lightbox with 100% toggle zoom and vertical scroll for full-page dashboards.
- **Decoupled Data Architecture**: All content is strictly typed and decoupled inside `data/` modules, acting as the single source of truth without database or backend dependencies.
- **Zero AI-Slop Discipline**: Purposeful, production-grade styling adhering to custom design tokens in `app/globals.css` without generic template clichés or broken affordances.

## Product Principles

1. **Engineering Transparency Over Hype**: Lead with verifiable code, real architectures, active GitHub repositories, and working demos rather than superficial design claims.
2. **Frictionless Evaluation**: Enable recruiters to inspect system architectures, examine 100% high-res screenshots, and copy test credentials within 1-2 clicks.
3. **Bilingual Precision & Parity**: Maintain equal literary and technical rigor across Thai and English; never treat translations as an afterthought.
4. **Performance & Code Integrity**: Maintain 100% clean linter audits, strict TypeScript types without `any`, and zero unnecessary runtime dependencies.

## Accessibility & Inclusion

- Keyboard navigability for all navigation anchors, interactive cards, modals, and the image lightbox (Escape, Arrow keys, Tab traps).
- High visual contrast ratios adhering to WCAG standards across both Dark and Light themes.
- Touch-friendly action targets (minimum 44x44px) and layout shift-free responsive design on all screen viewports.
